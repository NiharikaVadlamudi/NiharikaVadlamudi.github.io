As a Software Developer I on the **Torus Buildout** team (Experiences + Devices) at Microsoft, I built infrastructure for secure, sovereign cloud deployments.

- Automated and optimized cloud orchestration workflows, enabling two critical role bring-ups and reducing buildout time by ~5%.
- Developed and deployed a configurable certificate provisioning workflow in **CredSMART**, adding support for publishing public trusted root and public certificates to Azure Active Directory.
- Integrated the **Torus SecretsBootstrapper** service with two core services for end-to-end secret management enablement in sovereign cloud pipelines.
- Conducted integration testing for 30+ CredSMART APIs, supporting 100+ partner teams in secure service key and certificate workflows.
- Automated core security services (Lockbox, IDM) using the Buildout Coordinator Tool, and implemented the Torus Configuration Syncer Service for dynamic, code-free configuration management.

This work also won 3rd place among 20+ projects at the Microsoft Global Hackathon 2024, for a certificate troubleshooting tool built on this stack.
