At **Microsoft Research** (CARE Team), I work on multimodal vision-language models for radiology, in close collaboration with Narayana Health.

- **Rad-Phi4-Vision-CXR** {% cite vadlamudi2025radphi4 %} — a compact multimodal assistant for versatile radiology workflows.
- **CARE-X** {% cite vadlamudi2026carex %} — clinically useful radiology VLMs built with auxiliary supervision, reward-aligned learning, and tool-augmented measurement.
- **Aortic dilatation screening** {% cite vadlamudi2026eacts %} — a multimodal, geometric morphometric agent for early detection of borderline aortic dilatation on chest radiographs, developed independently in collaboration with the Narayana Health team.
- Tube detection and abnormality placement — dataset creation, model training, and evaluation for classifying tube placement and associated abnormalities in ICU pathologies.

This work spans dataset coordination with hospital partners, model evaluation against clinically defined exit criteria, and a systematic literature review of radiology foundation models.
